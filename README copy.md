# 🏦 ServiceBusinessApiCatalog

Catálogo de APIs REST especificado en **OpenAPI 3.0 (Swagger)** para el ecosistema bancario y financiero **ServiceBusinessBank**.

Este repositorio contiene la arquitectura modularizada del contrato de interfaz (Endpoints, DTOs, Schemas, Autenticación JWT y Manejo de Errores) consumido por el Backend en **.NET Core**.

---

## 🛠️ Tecnologías y Herramientas

- **OpenAPI 3.0** / **YAML**: Especificación estándar para diseño de APIs REST.
- **Redocly CLI**: Linter, bundler y servidor de documentación interactiva.
- **Node.js**: Entorno de ejecución para la automatización de scripts.
